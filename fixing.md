# Спецификация задач: Доработки Deposit, Statistics, Icons & UI Refactoring

## 1. Backend (Логика и API)

### 1.1. Модуль Депозитов (Deposits)
- [ ] Реализовать эндпоинты для управления депозитами.
- [ ] Добавить бизнес-логику расчета будущей доходности депозита (на основе процентной ставки, капитализации и срока).

### 1.2. Категории по умолчанию (System Categories Isolation)
- [ ] **Рефакторинг БД:** Полностью исключить глобальные системные категории (где `user_id IS NULL`).
- [ ] **Логика регистрации:** Создать сервис/сигнал, который при регистрации нового пользователя автоматически генерирует базовый набор категорий расходов и доходов, привязанных строго к его `user_id`.

### 1.3. Расширение фильтрации статистики
- [ ] Добавить поддержку фильтрации за текущий день (`day`).
- [ ] Реализовать фильтр для произвольного периода времени (передача параметров `date_from` и `date_to`).
- [ ] Унифицировать новые фильтры для 3 существующих эндпоинтов статистики.

## 2. Frontend (Компоненты и Интеграция)

### 2.1. Расчет доходности
- [ ] Создать UI-форму для редактирования параметров депозита.
- [ ] Выводить динамический расчет будущей доходности (интеграция с бэком).

### 2.2. Фильтры статистики
- [ ] Интегрировать в интерфейс статистики новые селекторы периода: "День", "Произвольный период" (дата-пикер) (завести их в табы что бы не грузить все сразу).

### 2.3. Замена иконок (Lucide Migration)
- [ ] Заменить все Emoji в селекторе выбора операций на иконки из библиотеки `lucide-react`.
- [ ] Добавить отображение и выбор `lucide` иконок в модуле настройки категорий операций.

## 3. UI/UX Refactoring (Темизация и Стили)

### 3.1. Тёмная тема (Dark Theme)
- [ ] Изменить основной цвет фона: заменить глубокий черный (`#000000`) на мягкий темный оттенок.
- [ ] Добавить легкое свечение (`box-shadow` / `drop-shadow`) для основных интерактивных и контентных элементов (возврат к первоначальному дизайну по референсу).

### 3.2. Светлая тема (Light Theme)
- [ ] **Нижнее закрепленное меню (Bottom Navigation):**
  * Убрать металлический цвет.
  * Сделать фон нейтрально-серым.
  * Добавить мелкую, резкую тень (`box-shadow`) для визуального отделения (эффект наложения меню поверх контента).
- [ ] **Слайдер счетов на Дашборде:**
  * Убрать статичный черный фон.
  * Реализовать серую обводку (`border`) с эффектом объема.

### 3.3. Общие элементы UI
- [ ] **Контейнер общего баланса:** Исправить баг темизации — компонент должен динамически менять свой цвет/палитру при изменении цветовой схемы в настройках профиля.
